Basic Chatbot using Python

Project Overview

This project is a simple rule-based chatbot developed using Python. It interacts with users and provides predefined responses to their messages.

Features

- Greets users with Hello, Hi and Hey.
- Responds to "How are you?"
- Introduces itself.
- Displays the current date.
- Provides help instructions.
- Exits when the user types "bye".

Technologies Used

- Python
- VS Code

Python Concepts Used

- Functions
- While Loop
- If-Else Statements
- User Input and Output
- Date and Time Module

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

"python chatbot.py"
